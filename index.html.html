                  Seus dados

                  Por padrão, tudo é salvo somente neste navegador/aparelho. Para ter os mesmos dados no celular e no computador, configure a sincronização abaixo. Mesmo sincronizando, faça backups de vez em quando.

                  Sincronização entre aparelhos

                  Conecta o app a uma planilha do Google (via um script seu, gratuito). Assim, o que você lançar no celular aparece no computador e vice-versa. Peça pro Claude o passo a passo de configuração caso ainda não tenha feito.

                  Backup manual

                  Como usar no celular

                  Abra este arquivo no navegador do celular e use o menu do navegador para "Adicionar à tela inicial" — assim você terá um ícone como um app, sem precisar abrir o navegador manualmente. Os dados continuam salvos localmente mesmo assim.
